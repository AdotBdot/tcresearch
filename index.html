    How to Use

    Basic Usage: Choose two aspects from your research note using the selectors on the left. Specify the number of blank spaces between them and click Find Connection. The tool will find the shortest path connecting them.

    Disable Aspects: If you're unhappy with a path because you lack access to certain aspects, disable them from the "Available Aspects" section. The search will then find alternative paths without those aspects.
